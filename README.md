# HW903 CSV 数据格式说明

版本：v1.2

日期：2026-09-03

## 1. 文件与行类型

- 文件可混有说明行（如 `NO.1 ... DeviceName:...`）、表头、HW903 数据行及 RR 行。连接 Polar 时，RR 可直接穿插在 HW903 数据之间，不一定重复 RR 表头。
- 使用 CSV 解析器逐行读取，分别保存各类型表头。**按实际表头名称定位字段，不固定总列数、列位置或报文长度。**尾部可能用空列补齐；不得删除行内空字段而使列错位。
- HW903 表头包含 `time`、`acc-x`、`acc-y`、`acc-z`，其余字段按该文件表头读取。
- RR 行使用独立结构：`time,RRInterval,timestamp,rawData`，后面可有补齐空列。`rawData` 为形如 `<164fe102>` 的十六进制字符串。
- 根据行结构和字段类型区分 HW903 与 RR；**不能把最近一个表头套用到所有后续行，也不能仅凭非空列数分类。**说明行和表头不计入样本数；无法唯一识别的行保留源行号并报错，不猜测、不静默丢弃。
- RR 按独立数据流保存，来源按采集信息确认；不能自动归为 HW903 输出，也不能与 HW903 按行号配对。

## 2. 时间

- **唯一主时间依据为第一列 `time`。**格式：`YYYY/MM/DD HH:MM:SS_mmm`，`mmm` 为毫秒；例如 `2026/08/19 14:31:08_086`。Python 解析格式为 `%Y/%m/%d %H:%M:%S_%f`。
- 其他 `timestamp` 仅保留为辅助字段。同名列在解析器内部按当前文件的原列号区分，例如 `timestamp_col2`，避免字段字典覆盖；同时保留原列名与列号。
- 时间字符串未指定时区；采样、接收或写入时刻的具体来源未确认，不自行补设。
- 保留各流原顺序、源行号、相同时间、时间倒退和间断。全文件可能不按时间排序；分别检查各流。不得仅按 `time` 或 `rawData` 去重，同一 RR 报文可能展开为多条不同间期。
- 如需相对时间，各流使用共同起点 `t0`，计算 `elapsed_s = (time − t0)`，单位为秒，并记录 `t0`。不按行号重建均匀时间轴，不用累加 RR 替换 `time`。

## 3. 字段

| 字段 | 含义与解析规则 |
|---|---|
| `acc-x`、`acc-y`、`acc-z` | 三轴 ACC；保留原始数值，物理单位和缩放按设备协议确认。 |
| `slot{s}-adc{p}` | 光学采集槽位 `s=0..4` 下的数字读数 `p=0..3`。**未采光学时，相关列可能不存在，不得要求固定存在或补零冒充观测。** |
| `slot{s}-gain{p}` | 各光学通道的增益相关字段，`p=0..3`。 |
| `slot{s}-current{c}` | 各槽位的发光驱动电流相关字段，`c=0..1`。 |
| 算法结果及状态 | 按下列原字段名读取；单位、比例、状态码和零值含义按对应协议确认。 |
| `RRInterval` | RR 流导出的间期原值；单位按来源协议确认，**不能默认毫秒，也不能用相邻 `time` 差代替。** |
| `rawData` | 原始报文字符串，完整保留；不能把示例报文的长度或字节布局当作所有配置的固定协议。 |

示例中出现的算法结果及状态字段如下；以当前文件实际表头为准：

```text
hr, spo2, total_step, hour_step, calorie, hrv, stress, resp, rhr,
shell_temp, vo2max, algo_device_mode, wear-diff0, wear_state,
sleep_score, sleep_status, deep_sleep, light_sleep, rem_duration,
awake_duration, fall_sleep-hour, fall_sleep-min, sleep_out-hour, sleep_out-min
```

槽位与发光组的对应关系：

| 字段前缀 | 控制的发光组 |
|---|---|
| `slot0-*` | 绿光组 1：位于对角位置的绿灯 `LED2`、`LED4`。 |
| `slot1-*` | 绿光组 2：位于对角位置的绿灯 `LED3`、`LED5`。 |
| `slot2-*` | 中心三合一 `LED1` 组中的绿光通道。 |
| `slot3-*` | 中心三合一 `LED1` 组中的红光通道。 |
| `slot4-*` | 中心三合一 `LED1` 组中的红外光通道。 |

`adc0..3` 与物理 PD（光电二极管）、`current0/1` 与具体发光器件的对应关系尚未确认。

**列不存在、单元格为空、数值为零是三种不同情况，分别保留；全零不自动解释为有效结果或缺失。**未知列保留原名与原值。

## 4. 采样率

- **HW903 采样流在单文件内使用统一标称采样率**，已知可为 25、50 或 125 Hz；RR 流不适用此约束。单秒点数及相邻时间间隔允许波动，例如 25 Hz 文件中某秒有 23 或 26 点，不据此判定采样率改变或丢样。
- 优先使用已确认的采集配置。配置未知时，仅对 HW903 数据流，在多个无明显中断的较长区段分别计算 `(N−1)/Δt`：`N` 为该区段样本数，`Δt` 为首尾 `time` 差，单位为秒；据此估计标称采样率，同时保留实际记录密度。
- 排除 RR、表头及说明行对样本计数的影响；不把长间断纳入连续区段的采样率估计。**不得只依赖文件名、单秒点数或相邻时间差中位数。**证据不足或各区段估计矛盾时标记“采样率未确认”，不擅自判为文件内变频。
- 解析阶段不为了凑齐标称点数而补点、删点或重采样。
