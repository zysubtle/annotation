# HW903 本地数据标注器

浏览器操作、本机保存，无云端账号或数据上传。Python 3.9+ 标准库实现，无需安装第三方依赖。只绑定 `127.0.0.1`，不用于互联网部署。

## 启动与保存位置

在仓库目录运行：

```sh
python3 -m annotator.server
```

macOS 也可双击 `start-annotator.command`。浏览器打开 `http://127.0.0.1:8000/`。终端/服务需保持运行；关闭服务不会删除任务，下次重新运行即可继续。暂不自动随开机启动。端口被占用时应先确认原服务，不要重复运行。

默认任务目录为 `~/Library/Application Support/HW903 Annotator`（macOS），其他系统为 `~/.local/share/hw903-annotator`。网页底部显示实际位置，可用 `--data-dir /具体目录 --port 8000` 指定。当前文件锁实现面向 macOS/Linux。

目录包括 `tasks`（活动任务）、`trash`（主动清理后的可恢复任务）、`staging`（尚未完成的上传/恢复）。同一目录只允许一个服务进程。系统崩溃残留的 staging 文件不会自动发布为任务，也不自动删除，以便诊断；可在确认服务停止且不需恢复时人工清理。

## 使用

1. **上传数据**：选择一个或多个 HW903 CSV；每批建立一个任务，一文件一记录。追加到当前任务使用“追加数据”。同一任务内内容相同的文件提示重复并跳过；重名但内容不同的文件独立保存。
2. **检查与标注**：逐记录查看检查信息。时间倒退、未知数据行、字段无法识别等错误阻止标注。修改数据需要在外部修正副本后重新上传，程序不改写原始字节。
   - 左侧默认只保留“记录”及文件数量。桌面宽屏悬停展开列表，移出后短暂缓冲再收起；“固定展开”用于连续切换文件。列表浮在内容上方，展开、固定均不改变波形宽度，当前文件名仍显示在波形上方。
   - 窄屏、触屏点击入口打开，点击外部或“收起”关闭；键盘可用入口按钮或方向键打开。`Esc` 优先回滚正在进行的拖动，否则只收起已打开的列表，不取消标注草稿。拖选、平移期间不响应悬停展开，切换记录仍需确认放弃未保存输入。
3. **选择区间**：在任一波形按左键拖选，全部 9 条曲线实时同步高亮；拖左右把手精调边界，拖选区内部整体移动。单击只放置光标；空格＋左键拖动平移视窗，普通滚轮仍滚动页面。“放大选区”可放大后继续微调，切换 PPG 槽位和视窗不会清除选区。也可展开“精调时间与备注”输入相对整数毫秒。
   - 松开鼠标只生成待确认区间。波形旁的“确认区间并保存”才写入磁盘；宽屏在右侧，窄屏位于波形上方。点击已存标签的“编辑”或波形顶部标签条后，确认修改才更新原区间；修改期间如需新建，先取消编辑。
   - `Esc` 取消草稿；若正在拖动则先恢复该次拖动前的状态，再按一次才清除草稿。鼠标手势中断、丢失捕获或窗口失焦也恢复拖动前状态，不会留下半完成的修改。
   - 重叠或超出记录范围会禁止确认；相邻区间可以共用边界。跨过 ≥1 秒记录时间间隔时提示核实但不禁止保存，该阈值沿用绘图断线规则，不代表已确认丢包。“已保存”只在服务确认后显示，毫秒显示也不代表鼠标有毫秒精度。
4. **算法对照**：下载本记录 JSON 模板，填写实际算法来源/版本与区间后导入。比对双方都有明确 EXERCISE/NON 标签的时间交集。未标注、无输出、UNKNOWN、TRANSITION 不自动当 NON，也不纳入差异时长。不会运行真实算法，不把算法输出自动当人工真值。
5. **下载结果**：ZIP 包含 `manifest.json`（无损恢复的权威清单）、每记录的 `annotations.csv`、已导入的 `algorithm.json`、说明。勾选“包含原始数据”导出完整任务包。生成包标记的是该版本的快照，不证明浏览器已成功存盘。
6. **恢复**：通过“上传数据”一次选择一个本工具导出的 ZIP。始终创建独立任务，不覆盖已有任务。结果包不含原始文件时，通过“补传原始数据”验证内容指纹与时间起点，再继续标注。完整包重新解析并校验所有原始数据后再发布任务。
7. **清理**：任务列表中输入任务名称确认，将任务移入本地 `trash`，不永久删除，不自动减少回收区占用。需要恢复时，先停止服务，把该回收目录移回 `tasks/<task.json 中的 id>`（目标必须不存在），重新启动服务。重要数据仍需自行备份。

## 首版边界与数据契约

- 只支持 [HW903_format.md](HW903_format.md) v1.4；WBX61 不支持。RR 独立识别并保留在原始文件中，不显示为生理事件参考轴。
- 以第一列 `time` 为主时间。各流共用文件内最早可解析时间 `t0`，单位为整数毫秒，时区保持未确认。HW903 标注范围由 HW903 流决定，不被晚到的 RR 延长。
- 标注为 `[start_ms, end_ms)`，结束不含；最后一条 HW903 记录时间加 1 ms 只用于让半开区间包含末记录，不表示已经观测到额外采样时长。未标注不等于非运动；标签轨道内不允许重叠。
- ACC 用浮点除法从 µg / 1000 转 mg。PPG 五个槽位可选，每个四 ADC 同时显示；不存在的列、空单元格、数值零分别保留。未知字段和同名 timestamp 的列位置保留在原始文件和表头清单。
- HR 和 `total_step` 显示原值，不自行解释零值有效性；首版不派生 `delta_step`，避免在计数周期/完整秒条件未确认时给出错误增量。
- 暂不自动确认标称采样率。样例虽名为 25Hz，不能据文件名决定时间轴；实际按 time 绘制。显示时相邻间隔 ≥1 秒断线，这是明确标注的绘图工程规则，不是已确认的丢包阈值。
- 波形按请求视窗读取，宽范围只对绘图采用分桶极值抽稀，保留空值断点；原始数据不抽稀，标注仍使用完整时间。保留源行号、重复时间与流内原顺序。
- 保存有任务版本冲突检查，拒绝过期页面覆盖新版本。人工标注修改前快照保存在每记录 `history` 目录，界面暂不提供历史版本回退。自动保存的原子写入以磁盘/操作系统正常工作为前提，不代替硬件故障备份。
- 首版资源上限：单 CSV 64 MiB、每任务最多 500 文件且原始总量 256 MiB、任务元数据 32 MiB、ZIP 上传及解压总量 512 MiB。这些是保护本机资源的工程默认值，不是设备格式上限。超限明确报错，需拆批。
- 清单保留备注原文；面向 Excel 查看用的 CSV 对公式样式文本加前置单引号，防止被当公式执行。恢复以 `manifest.json` 为准，不解析手工编辑过的导出 CSV。
- 上传使用同源检查和每次启动随机令牌；无跨域 API。文件名不作为磁盘路径，ZIP 不使用任意路径解压。数据不上传云端，但对能访问本机文件的其他本地程序不提供隔离保证。

## 本地接口

读取 `/api/config` 获得本次服务令牌；所有写请求必须带本服务的精确 `Origin` 和 `X-Annotation-Token`。JSON 写请求为 `application/json`，文件上传为 `application/octet-stream`，必须提供 Content-Length。

- `GET /api/tasks`、`GET /api/tasks/{task_id}`：列表/任务详情。
- `POST /api/tasks`：`{"name":"任务名"}`。
- `POST /api/tasks/{task_id}/files?filename=...`：单文件；界面按批顺序调用，单文件失败不回滚其他记录。
- `GET /api/tasks/{task_id}/records/{record_id}/plot?start=0&end=30000&fields=acc-x,slot2-adc0`：相对毫秒视窗绘图数据。
- `POST .../records/{record_id}/annotations`：`revision`、完整 `annotations` 列表、`completed`。
- `POST .../records/{record_id}/algorithm`：`revision`、`sha256`、`t0`、`version`、`intervals`。
- `POST .../records/{record_id}/attach?revision=...`：结果包补传原文件，必须匹配指纹，重新校验人工与算法区间。
- `POST /api/tasks/{task_id}/export`：`revision`、`include_original`。返回下载标识，再 `GET /api/tasks/{task_id}/exports/{export_id}`。
- `POST /api/restore`：本工具 ZIP 任务包。
- `POST /api/tasks/{task_id}/trash`：`revision`、`confirmation`（任务名）。仅移动到回收区。

浏览器支持 WebMCP 时额外提供只读任务列表和打开已有记录的工具；不支持时不影响普通界面。兼容性检测及接口存在不等于已在所有浏览器验证 WebMCP。

## 验证

```sh
python3 -m unittest discover -s tests -v
node --check annotator/web/app.js
node tests/frontend.test.cjs
```

测试使用独立临时目录，不往用户任务库插入测试标注。覆盖真实样例、缺列/空值/零值、RR 混排行、时间异常、保存/版本冲突、完整与结果包恢复、指纹拒绝、路径/来源检查和前端状态逻辑。Node 测试是受控 DOM/画布替身下的运行检查，不等于实际浏览器点击或视觉验收。
